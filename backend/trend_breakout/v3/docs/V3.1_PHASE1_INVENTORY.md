## 2. A+ / OVERHEAT / universe — exact locations

### Plan A+ (authoritative for user board)
- **Definition**: `v3/grading.py::grade_candidate` + `v3/config.py` candidate matrix.  
- **Not** `RecommendationScore ≥ 90`.  
- Call sites: `TrendConfirmationBot`, `publish_close_v3`, `backfill_plan_a_plus_daily`.

### OVERHEAT → WATCH cap (V3.0 pain point)
```text
v3/grading.py  ~L199–221
  if overheated or life == OVERHEATED:
      reasons.append("OVERHEATED: max WATCH")
      → Grade.WATCH (or FILTER)
```
Also: `config["candidate"]["filter"]["block_overheated_from_core"] = True`.

### Consumption hard gate
- A+ `consumption_max: 70` in config; `_consumption_ok` fails band if cons ≥ max.  
- Source score: `ContinuityEngine` / `v2_continuity.score_consumption` (session-global, not wave-scoped).

### Universe top600
- Backfill: `backfill_plan_a_plus_daily.py` `MAX_UNIVERSE = 600`, `prefilter_codes` sorts by MA20 10d slope.  
- Live scan: spot prefilter ~250 + `local_prefilter_boost` (smaller than 600).  
- Kill reason `NOT_IN_TOP600` = missed backfill universe (e.g. 600396 2024-05-08, 2026-03-06).

### RecScore vs Plan
| | Plan A+ | RecScore |
|---|---|---|
| Style | Multi-dim **hard AND** | Weighted avg + resonance bonuses − cons penalty |
| Monthly / sector day-trend | Not in Plan mins | In score + tags |
| OVERHEAT | Caps Plan ≤ WATCH | Score can stay A/A+ |
| Fund 65–70 | Hard fail A+ if present | Soft weight |
